Self-initiated project · Fictional business

Harbor Plumbing Co. Small business website with Elementor

Problem

A local service business needs a site that earns trust quickly and gets visitors to call or request an estimate, on any device.

Process

  • Started from a fresh WordPress install and planned the page as a wireframe first
  • Built it in Elementor on Hello Elementor with global colours and fonts: hero with calls to action, services, "why us", reviews and a contact form
  • Working Contact Form 7 request-a-callback form
  • Hardening: login attempt limits, XML-RPC disabled, security headers, file editing off, WordPress version hidden, user list blocked

Result

A clean, responsive homepage with a clear call to action on desktop and mobile, plus a reusable Elementor template.

Self-initiated project · Fictional business

Olive & Ember Bistro Redesign & bug fixes with measured results

Problem

A restaurant site (a theme I built with common real-world bugs on purpose) looked broken on phones and loaded slowly. I audited it like a client site and found 8 issues:

  1. Sideways scrolling on mobile
  2. Menu overlapping the logo
  3. Stretched food photos
  4. Low-contrast text
  5. Three different button styles in one row
  6. Broken 3-column card grid
  7. 20 MB of uncompressed images
  8. 2 console errors

Process

  • Found the overflowing elements with DevTools before changing anything
  • Fixed everything in a child theme, so the parent theme stays untouched and updatable
  • Added a proper mobile menu, unified the buttons, rebuilt the grid, compressed images to WebP

Result (Lighthouse, measured on a local test server)

Mobile performance71 → 89
Desktop performance75 → 99
Accessibility93 → 100
Page weight20.9 MB → 476 KB

Process

How I work

The same five steps on every job, so you always know what's happening and nothing breaks unexpectedly.

  1. 01

    Audit

    I review the site, the goal and what's broken. For fixes, I reproduce the problem first.

  2. 02

    Plan

    A short written plan or wireframe with scope and timeline, agreed before I start.

  3. 03

    Build

    Clean work in Elementor, WooCommerce or a child theme, on a backup or staging copy where possible.

  4. 04

    Test

    Desktop, tablet and mobile checks, forms and checkout tested, speed measured with Lighthouse.

  5. 05

    Handover

    Before and after screenshots, notes on what changed and how to manage it yourself.
